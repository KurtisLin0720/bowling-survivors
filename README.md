# 🎳 保齡球特攻 Bowling Survivors

一款以保齡球為主角的單檔 HTML 生存遊戲，可直接在瀏覽器遊玩，支援桌面與手機。

## 遊玩方式
- 電腦：使用 **WASD** 或 **方向鍵** 移動。
- 手機：在遊戲畫面按住並往想移動的方向拖曳。
- 球瓶會自動攻擊附近的怪物。
- 擊敗怪物取得經驗值，升級時選擇一項強化。
- 撐得越久，怪物會逐漸變強。

## 專案內容
- `index.html`：完整遊戲，無需安裝套件或建置工具。
